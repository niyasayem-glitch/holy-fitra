## Selection rationale

Candidate 1 is selected for implementation because it is small enough to validate immediately but foundational enough to affect the entire language. The current seed lowers Boolean operators with eager LLVM `and`/`or` instructions. That behavior is inconsistent with the short-circuit source semantics used by the self-hosted lexer and can trigger invalid accesses, unnecessary tool/model work, or safety-sensitive calls on the right-hand side. A control-flow lowering fix is therefore both a correctness breakthrough and a safety/performance primitive.

The implementation will preserve ordinary scalar expression composition while lowering `left && right` and `left || right` through explicit branches and a `phi i1`. The existing `if` and `while` emitters already provide the label-generation pattern needed for this change. The candidate will be retained only if the new fixtures prove RHS non-evaluation, all existing bootstrap fixtures pass, the full Python suite remains green, and the Termux/native/AArch64 gates remain green.

## Longer-horizon breakthrough path

After short-circuit lowering, the fastest route toward a real Stage-1 compiler is a bounded string/byte output ABI, followed by a self-hosted symbol table and type checker. The LLVM emitter should be implemented only after these primitives exist; otherwise the project risks replacing Python with a fragile fixed-buffer demo rather than producing a reproducible compiler. The fixed-point milestone should compare canonical diagnostics, token/AST serialization, emitted LLVM text, and native artifact identity rather than relying only on executable exit codes.

## Selected candidate verification

Candidate 1 was implemented and retained. Stage-0 now lowers `&&` and `||` through explicit conditional branches and `phi i1` merge values. The dedicated `bootstrap/short_circuit.hf` fixture places an intentionally invalid `hf_dyn_i32_get32` operation behind both a false `&&` branch and a true `||` branch; the executable returns successfully without triggering the runtime abort. The generated LLVM contains the expected `phi i1`, and the fixture passes ASAN/UBSan.

The full applicable Python suite remains at **168 tests with 0 failures**, the Termux-compatible host gate remains at **129 tests**, and the updated no-Python bootstrap gate passes the new short-circuit fixture, self-hosted frontend, scalar, aggregate, I/O, diagnostics, sanitizer, AArch64, and Python-free checks. Candidate 1 is therefore **retained**. Candidate 3, the bounded byte-buffer/string-builder ABI, is now the next implementation target because it unlocks self-hosted diagnostics and LLVM text emission without fixed-size output hacks.
